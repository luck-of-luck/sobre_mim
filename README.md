### 📡 Projeto em Destaque: Ampliagro OS
Idealizador e desenvolvedor principal do **Ampliagro**, um ecossistema de gestão agrícola de elite estruturado sob o conceito de **Bento Workspace OS**. O projeto redefine a usabilidade no campo ao transformar dashboards tradicionais em uma verdadeira área de trabalho de alto desempenho:

* **Matriz Cartesiana Snapping**: Telas dinâmicas baseadas em malhas rígidas simétricas de alta densidade (resoluções de 30 e 160 colunas), permitindo o dimensionamento perfeito de widgets analíticos diretamente por suas alças laterais intermediárias.
* **Design de Código NCS**: Interface tipográfica plana e minimalista, livre de poluição visual (sem sombras, relevos ou bordas flutuantes), projetada estritamente sob as paletas de cores industriais estáveis e inversões cromáticas reais (NCS #006b68 / NCS #f87e08).
* **Arquitetura Offline-First & SPA**: Aplicação de página única (SPA) assíncrona robusta rodando sobre Django no backend e Vanilla JavaScript nativo no frontend, integrada com motores de telemetria passiva para monitoramento de sinal e estado de rede local.
